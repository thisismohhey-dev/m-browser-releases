# M. Browser

A fast, light desktop browser for Windows that keeps its memory use low and brings the things Iranian users reach for every day to its home page: a Jalali calendar, prayer times and currency rates.

## Download

Get the latest installer from the **[Releases](../../releases/latest)** page: `M-Browser-Setup-<version>.exe`.

- Windows 10 / 11, 64-bit. Installs for the current user only; no administrator rights needed.
- The installer is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Choose **More info → Run anyway**.
- M. Browser never changes your default browser by itself. You can choose it in Windows Settings → Default apps.

## Updates

The app checks this page's latest release by itself (Settings → Updates) and offers to restart when a new version has been downloaded. You can also press **Check for updates** at any time.

## What it has

- Tabs, tab groups, workspaces, Side Apps (YouTube Music, Castbox, Spotify...), favorites, history, downloads
- Find in page, zoom per site, picture-in-picture and a floating video player, a mini media player
- Passwords stored encrypted on your computer, InPrivate windows, built-in ad blocking
- Optional Google sign-in to sync favorites, settings and passwords (passwords are sealed with a passphrase only you know)
- Home page with Jalali / Gregorian calendar, events, prayer times, weather, currency and gold rates

## Privacy

Nothing is collected and there is no account. Everything stays on your computer unless you turn on Google sync. See the [privacy policy](https://m-browser-513407.web.app/privacy).
